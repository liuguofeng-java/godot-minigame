## 限制与未测项

浏览器验证使用模拟 wx 文件系统和下载接口，真实 WASM 与 Brotli 解码器执行资源加载。它验证启动协议及导出资源完整性，不能替代微信宿主的 API、缓存配额、域名配置及手机内存/性能验收。

面板排版预览复用实际面板脚本及导出的 Godot 编辑器主题，在隐藏 Edge 内渲染示例数据；3.0.0 删除入口后的尺寸、页签、鼠标操作及配置同步通过无窗口编辑器回归。此次重跑全项目实际导出及 WASM 场景加载；沿用现有支持 `--extra-pack` 的 3D 引擎，没有修改原生补丁或重新编译引擎。

显式指定启动场景通过内存中的 `override.cfg`，符合 Web 模板禁用命令行路径覆盖的构建方式；原工程和发布包中的项目设置保留。场景切换下载、挂载和就绪在真实引擎中执行，下载及缓存接口由测试宿主模拟。

微信开发者工具与 Android/iOS 真机尚未验收，也未连接实际 CDN。浏览器控制台只有已有 `ScriptProcessorNode` 弃用提示，没有脚本或资源加载错误。性能和画面一致性不属于本次启动检查结论。

本地日志与产物保存在忽略跟踪的 `build/`、`dist/` 和 scene-test 的 `output/`，不随源码提交。
